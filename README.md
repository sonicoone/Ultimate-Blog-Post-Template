## 📋 Overview

Traditional SEO templates are dead. In the era of AI Overviews and entity-driven search, ranking requires more than keyword placement—it requires **content engineering**.

This repository contains the fully integrated v5.0 template and Standard Operating Procedure (SOP) designed to be your team's single source of truth. It transforms static writing guidelines into a dynamic, data-driven system with automated research, tiered quality gates, conversion architecture, and lifecycle management.

-   **SEO Teams** building topical authority in competitive niches
-   **Content Ops Managers** scaling production without sacrificing E-E-A-T
-   **Product-Led Growth Teams** turning organic traffic into qualified leads
-   **Agencies** delivering future-proof content strategies for clients

## ✨ Key Features

### 🧠 AI & Entity Optimization
-   **Automated Entity Brief Generator:** AI prompt included to extract entities, schema types, and authoritative sources from top SERP results—eliminating manual discovery friction.
-   **AI Overview Engineering:** Week-2 post-publish protocol to analyze, match, and lock in AIO citation structures.
-   **Zero-Click Formatting:** Direct answer blocks, structured lists, and semantic HTML optimized for machine parsing.

### 🛡️ Tiered E-E-A-T with Quality Gates
-   **3-Tier Evidence Matrix:** Tier 1 (Original Data), Tier 2 (Curated Expert), Tier 3 (Practitioner Commentary)—each with minimum viable proof requirements.
-   **Rejection Flags:** Explicit criteria for editors to reject briefs/drafts that don’t meet tier standards *before* wasted production time.
-   **Experience Block Architecture:** Mandatory, tier-dependent evidence sections placed at optimal positions for trust signaling.

### 💰 Conversion Architecture
-   **Contextual Relevance Rule:** Micro-conversions only placed when H3 discusses a specific action/problem AND the CTA offers a direct solution—preventing banner blindness.
-   **Peak Intent Mapping:** Conversion opportunity identification during Phase 0 strategy, not as an afterthought.
-   **Friction Audit Checklist:** Ensures primary tasks are completable without unnecessary interstitials or form fields.

### ♿ Accessibility as AI Parsing Requirement
-   **Semantic HTML Linter Gate:** Mandatory validation of `<article>`, `<section>`, `<figure>` tags before publication.
-   **Transcript Requirement:** Full text transcripts for all media (critical for both WCAG compliance and AI indexing).
-   **Reading Order Validation:** DOM order must match visual layout for keyboard navigation and screen readers.

### 🔄 Lifecycle & Decay Management
-   **Freshness Sprint Protocol:** Trigger-based repair checklist activated when Tier 1 posts lose >20% clicks in 90 days.
-   **6-Month Pruning Decision:** Merge-or-enrich framework for underperforming content to preserve crawl budget.
-   **Bidirectional Cluster Weaving:** Post-publish internal linking updates to send immediate authority signals.

### ⚙️ Operational Scalability
-   **Writer Self-Check Gate:** 9-point pre-submission checklist reducing editorial back-and-forth.
-   **Content Production Brief Template:** Structured brief pulling all Phase 0/1 decisions into a single writer handoff document.
-   **Anti-Pattern Reference Table:** Quick-reference guide for outdated vs. modern practices.

## 🚀 Getting Started

1.  **Clone or Fork** this repository
2.  **Copy the v5.0 Template** from [`/template/v5-seo-blog-sop.md`](./template/v5-seo-blog-sop.md) into your team’s wiki, Notion, or CMS documentation
3.  **Run the Entity Brief Generator Prompt** (included in Phase 0) with your AI research tool for your next assigned keyword
4.  **Assign Content Tier** using the matrix before any drafting begins
5.  **Enforce the Writer Self-Check Gate** before editorial review
6.  **Track AIO Citations** at Week 2 post-publish

> ⚠️ **Critical:** Do not skip Phase 0. The entire system depends on completing SERP, Entity, and Tier analysis *before* writing begins.
